# Meeting Assistant — Feature List (EN)

> Derived from **BRD Meeting Assistant v1.0** (Section 5 — Functional Requirements) plus proposed production & admin features.
> **Is Done?**: `[ ]` = not done / to be built (all unchecked — fill in as you go).
> **Constraint**: which feature(s) this one depends on (by Feature Code). `—` = no dependency / entry point.
> **Module prefixes**: REC=Recording · PRP=Processing Pipeline · MTD=Meeting Detail · RAG=Chatbot · CAL=Calendar & To-do · MMG=Meeting Mgmt · AUT=Auth & Roles · ADM=Admin · PRO=Proposed (Phase B).
> **Production / hardening (Phase A & C)**: REL=Reliability · PRV=Privacy & Data · OBS=Observability · SEC=Security · OPS=DevOps · CST=Cost & Scaling · COM=Commercialization (SaaS).
> **Note tags**: *Blocker* = blocks production · *Mandatory* = needed for any path incl. internal · *SaaS* = only when commercializing.
